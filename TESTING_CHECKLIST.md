# PartyBox — Manual Playtest Checklist

Covers the 18 online multiplayer games from `BACKLOG.md` (the 17 numbered
concepts + Teri, which was specified directly and built alongside them).
Doesn't include FirstBell (predates the backlog) or the offline solo tools
(ThinkFast, Tez Hisab, Spot the Jugaad, Desi Memory Master, Dumb Charades
offline) — say if you want those added too.

## How to test

1. Go to `/test-lab` (direct URL, not linked from Home).
2. Pick the game, set a player count (4-5 is a good default), hit **Create
   Test Room**.
3. Open each player link it gives you in its own tab or window
   (⌘/Ctrl-click, or the "Open →" button opens a new tab already). Each tab
   gets its own isolated identity for as long as it stays open, so you can
   play every seat yourself from one machine.
4. Resize at least one tab to a phone width (or use a real phone against
   the same URL) to cover mobile; leave another at normal desktop width.
5. Play a full round through — lobby → gameplay → results — on both.

Check off **Desktop** and **Mobile** independently once a full round looked
and worked right on that layout. Add a one-line note under any game where
something looked off; I'll pick it up from there.
